# Retail TH07 final-card practice collector

The actor samples direction (nine states), focus, shoot and Bomb from its frozen TorchScript policy. It sees grayscale gameplay and its difference from the previous policy camera. The separate read-only spell monitor records the native phase and supports outcome verification.

Supply private retail TH07 v1.00b, the official thprac v2.3.1.1 executable and a lane image with Wine32, Xvfb, PulseAudio, xdotool and scrot. The driver verifies the SHA-256 of both retail files and thprac before opening a fresh game in tmpfs. Build the passive observer on the lane architecture with `cc -O2 -static spell-monitor.c -o spell-monitor` and place it beside the Python driver. The original actor and current/previous recording-slot reader are supplied by the parent practice collector.

`run-roster.py --help` lists the local asset, actor, policy and registration arguments. A run reads each case’s fixed seed, cap, scene and CPU allocation. After the true native endpoint, the original Save Replay menu can export a file under the credit’s `official-replays/`. Run `python verify_original_replay.py PATH_TO_COMPLETED_CREDIT` to independently decode its original T7RP stream and compare both native input slots across five clock offsets.

The published evidence includes the authentic last spell name, the active native card ID, end-of-stage tally and replay-save prompt. A practice section completion and an awarded no-miss spell capture are separate outcomes. The public result directory includes the source archives and measured clock offsets from a fresh replay in the retail executable.
