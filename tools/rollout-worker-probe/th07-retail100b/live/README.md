# Original retail Game Start controller

Use the same private installation and experiment root as the retail human replay bank. Stage this directory under `record/tool` and the read-only `native_input.c` and `inspect_rpy.py` helpers from the parent acquisition next to their consumers. On the experiment host the compiled helper command was `gcc -O2 -o record/tool/record_actor record/tool/record_actor.c -ldl`. Compile for the same libc as the game container.

The engineering acquisition uses `record/protocol.json` from `th07-retail-live-qualification`. Each new private profile goes through the official Game Start, Normal, Reimu and Homing Amulet menus. `boot.py` records these menus before entering ordinary play. `play_record.py` samples all four policy heads and waits with the original game suspended at each fourth tick until the requested keys are applied. Its only model inputs are grayscale camera observations. The observer's independent read-only native file descriptors supply verification fields and the official terminal state. Both engineering games started their policy on tick 4.

`post.py` recognizes the confirmed original negative Continue selection, preserves the complete score card, and then saves the official RPY from the game interface. `verify_record.py` checks the observed current and preceding keys at different candidate phases against this RPY, the in-game record buffer, every applied mask, real stage and resource fields, and the native terminal. The final partial decision can span a real transition into the Continue state. Its remaining original word counts only when the native event index, current input and original record slot agree. The complete-window statistic is reported separately from this partial window.

Stage the fixed held plan as `record/held-protocol.json`. After both engineering receipts have been verified, `python3 -u record/tool/pairs.py` runs the registered campaign. Two named instances use distinct output directories and container names per arm and controller seed. The collector watches each credit for 45 minutes. Any actual Stage 6 transition to the original Ending state is archived separately; the original display stays available for independent ending, score and official RPY navigation. Technical failures are archived with the predeclared replacements and all valid pairs keep their assigned physical host. The two games' internal RNG states are independent.
