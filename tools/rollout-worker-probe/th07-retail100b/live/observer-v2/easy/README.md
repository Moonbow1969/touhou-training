# Easy original credit qualification

Overlay these files on observer-v2/record/tool to run an isolated retail 1.00b ordinary Easy Reimu A credit. The ordinary menu helpers, native executable and controller come from the signed retail recording installation. The menu presses Up once from default Normal rank. The native observer and official replay decoder independently require Easy. The stock metadata, current/previous words, shot, final saved replay, resource checks and native maximum-time limits remain intact.

The first four subjects used isolated original games on two Momentum CPU sets. The quiet study has a fresh easy-quiet/record/tool, the designated host's installed compatible Wine image selected in boot.py, and protocol.json in record/. Compile canary.c with cc -O2 -Wall -o canary canary.c, then invoke python -u tool/quiet.py from record/. The canary uses an independent physical core and one-millisecond absolute monotonic deadlines. It records late and missed deadlines and the timestamp of each one-second maximum. The host monitor samples on another core. Both terminate after the fourth original ends.

Invoke seal_easy.py with the study root and boss-name-template.npy to write strict and all-attempt results and retain the original screenshots. The Green Spell human Stage 1 template is included with the first study. All eight feasibility decisions are screening cases.
