# A candidate for faster TH12 rollouts

Tweet-META/th12 implements the retail *Undefined Fantastic Object* 1.00b game logic in C++20 and provides a WebAssembly front end. The standalone C++ modules could support an actor that advances a chosen number of simulation ticks per decision and renders only the frames needed for inference. We reviewed commit `cc99fadaf9f2532fb2d7516a724f7fe63b5d428b` from October 25, 2026. Rollout throughput and visual-policy transfer on this core remain unmeasured in Moonbow. [Pinned source and build instructions](https://github.com/Tweet-META/th12/tree/cc99fadaf9f2532fb2d7516a724f7fe63b5d428b) · [C++ module structure](https://github.com/Tweet-META/th12/blob/cc99fadaf9f2532fb2d7516a724f7fe63b5d428b/docs/CPP-RESTORATION.md)

**Native parity.** Upstream checks individual behaviors against original code, including random-number generation and replay decoding. Its Windows frame inspector aligns captures by the original replay input cursor. The authors explicitly leave complete cross-stage behavior and screen timing open. A parity evaluation should replay the same retail file on both engines and locate the first differing tick in input, player state, enemies, bullets, item economy, or stage progression. It should also compare the camera pixels consumed by the actor and report any disagreement in deaths, Bombs or Stage 2 entry. **Benchmark provenance.** Every TH12 rollout in the November 26 native cohorts used the official 0.02a trial executable under Wine, SHA-256 `c6d15044394a33d6116c09eac44b33fdec814541c78518e29f60d54f49bdbd3a`. A simulator targeting retail 1.00b changes both the implementation and edition, either of which can affect a measured outcome. A future simulator result therefore needs its own engine, edition and checkpoint identifiers. A policy trained there can be evaluated using the existing original-game protocol. Retail assets are supplied by the local game owner. [Upstream license scope](https://github.com/Tweet-META/th12/blob/cc99fadaf9f2532fb2d7516a724f7fe63b5d428b/NOTICE.md)
