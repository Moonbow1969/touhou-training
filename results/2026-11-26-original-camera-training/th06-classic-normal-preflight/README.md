# TH06 Classic original Windows preflight

The already installed Steam TH06 Classic 1.03 release displayed its title in a disposable Windows profile using the official 640×480 window mode. The executable is 64-bit, so the legacy 32-bit TH06 addresses have not been assumed. The menu input attempt ended before sending gameplay controls when the original window failed to acquire the required foreground. No qualification or policy game is counted.
