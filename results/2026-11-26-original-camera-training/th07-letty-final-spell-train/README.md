# Normal Letty final spell on retail TH07 1.00b

Eight fresh controller seeds began at Normal Stage 1, Reimu A with two spare lives, three Bombs and Power 128. The unchanged six-game PPO parent sampled all four action heads every four native ticks. All eight reached the original Stage Clear tally after Winter Sign “Flower Wither Away”. Six passed strict native input timing. The remaining two (21749603 and 21749607) stayed in the physical denominator. No run earned a confirmed spell capture. This task starts at the last boss card, so ordinary Game Start progression requires its own evaluation.

The original game wrote eight replay files. Across 20,879 retained native observer rows, the decoded official replay matched both the current and previous original key word at offset zero. We then played the first exported replay in a fresh private copy of retail TH07 with thprac. Without controller input during gameplay, it reproduced the original Normal ID7 card and reached native Stage Clear. During the active card, every one of its 2,346 sampled input words matched the saved replay at stage clock minus one. This playback clock offset was measured independently.

The eight games generated 4,178 decisions and 8 spare losses. The predeclared training-budget rule moves one attack earlier if seven or eight baseline attempts already complete. We therefore kept these recordings and moved to Boss Nonspell 2. No policy update was attributed to this final-card pilot.
