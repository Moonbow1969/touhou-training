# Five-title visual dynamics on Hard and Lunatic

Two small networks learned to predict future playfield images from 60 original full credits, with six training games in each title and difficulty cell. Twenty other complete credits supplied 7,771 held starting points. There were 30,452 distinct training starting points and 76,800 sampled windows per model. Neither fit used the official paired PPO evaluation games. One model took original movement, focus, shot and Bomb decisions as input. The matched comparator saw the same images with constant key features. Both shared initialization, sample schedule, update count and parameter count. [Sources and registered measurement](protocol.json) · [Action-model trace](camera_keys-training.json) · [Image-model trace](camera_only-training.json)

At four decisions ahead, repeating the latest camera image gave 44.23 grayscale levels of mean absolute error on changing pixels. The image-only model reduced this to 28.23. The action model scored 28.30 with the real commands and 28.37 when its commands were shifted within each credit. The action model minus the image-only network scored +0.071 levels, with a stratified paired 95% interval [+0.040, +0.102]. This objective mostly measures predictable visual change. The models have yet to control an original game or improve a PPO return. The inputs were two 56×48 grayscale playfields and the next four recorded commands. At evaluation the commands after the first decision can reflect a reaction to intervening gameplay. An action-conditioned forecasting gain on those sequences measures observational predictability. Error was measured on both complete images and pixels differing from the last observed frame by more than 10/255, with equal weight per original game.
