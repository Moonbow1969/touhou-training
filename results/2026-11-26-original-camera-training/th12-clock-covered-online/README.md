# TH12 control cadence during original game play

Both trained policies completed 16 full evaluation credits under the four-native-tick controller. At each difficulty, each policy reached Stage 2 in 0/8 credits and finished with zero spare lives. Changing the training cadence from 120 ms to four native ticks shifted mean Stage 1 progress by −57 native ticks on Hard (paired 95% interval −590 to +452) and +282 on Lunatic (−17 to +608). Mean terminal Bomb stock changed from 0.875 to 1.25 on Hard and from 1.25 to 0.625 on Lunatic. The Lunatic policy trained at four ticks lost its first spare 2.94 seconds earlier on average (0.28 to 5.87 seconds earlier). These estimates pair seeds within the same physical hosts. Original game RNG could still differ between runs. An audit of the timing of the final input identified a distinction between requesting input and the game consuming it. In original 120 ms credit 1401204, the last requested input first took effect at tick 2,457. The game consumed the preceding input when the final life was lost at tick 2,456. The frozen study used its registered decision-window definition and included all 379 requests. A separately reconstructed live-input view contains 378. Future results using the stricter definition carry a separate registration.
