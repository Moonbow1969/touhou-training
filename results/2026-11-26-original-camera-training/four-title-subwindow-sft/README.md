# Two commands from one camera observation

The four-title camera SFT trained two matched-capacity action heads using the same 148,415 distinct training windows and 192,000 sampled windows per arm. The frozen image encoder saw the current original screen and the preceding image difference. One control issued a single command for all four native ticks. The candidate predicted two successive commands, each lasting two ticks, using the same initial image.

On previously used development players the two-command model lowered movement negative log likelihood per native tick in each game. The candidate-minus-control differences were −0.0160 in TH10, −0.0250 in TH12, −0.0159 in TH13 and −0.0191 in TH17. Each title weights its development players equally. Four new TH17 players were reserved separately. Effective subcommands and survival during native play require independent original-game checks.
