# Whole-credit full-action SFT and distributed PPO

All three original games use the same stochastic policy with four categorical heads: nine movement directions including neutral, focus on/off, shoot on/off and Bomb on/off. These produce 72 combinations. The games receive real keyboard input. TH13's optional title-specific manual Trance is outside the shared action space. The game still applies native mechanics, including death trance. Each worker carries the policy across life losses and Stage 2 and stops only on a verified native ending or Game Over. There are no Continues, geometric dodges, aiming corrections, or automatic Bombs.

Momentum's 5090 fitted a portable four-head SFT student using TH13/14/17 human replays and a previously trained structured human policy teacher. We used 216,350 original four-tick examples, resulting in 106,933 consecutive eight-tick action windows. The portable SFT objective mixes 85% human action targets and 15% teacher probabilities. Player groups in the four development replays are disjoint from training. The baseline uses two prior full controls and elapsed decision estimates; the historical replay shards have no corresponding original video. Its 84 visual input weights start at zero. Online PPO changes the weights using current image brightness and frame differences in a 6 × 7 grid. The directly evaluated human SFT and the PPO initialization have exactly the same binary fingerprint. The first synchronous PPO update barrier received four native full credits per title (12 credits, 8,304 accepted decisions) from the frozen SFT. Training seeds are distinct from all evaluation seeds. Entropy and Steam Deck are separate TH12 deployment hosts. TH13 plays on Endeavour; TH10 plays on Momentum and Accelerator. Workers sample their own actions and journal all four action log probabilities, value estimates, visual features, input confirmation, true stage, death and resource events. The learner recomputes all recorded probabilities before updating. Each minibatch assigns each title the same loss weight. A native spare loss (including the active final life) costs 1, an earned life receives 1, stage advance receives 2, a confirmed Bomb on the same life costs 0.03, and valid play earns 0.001 per wall second. TH10 spends Power on Bombs. Its item-derived Power balance and successful activations are reported separately. The native test is whether the original game actually enters Stage 2 during a whole credit. Record original stocks at that entry, and at the final native screen. If nobody enters Stage 2, the entry balance is undefined. Controllers share random seeds in matched test credits; native game RNG is uncontrolled. Technical interruptions are recorded separately. The fixed test uses 12 seeds per title per policy. A second barrier requests eight new credits per title using PPO1 and the same training objective. [Round-two design](protocol2.json)

From the repository root a completed first-round checkpoint can be rebuilt from the released action trajectories:

```sh
d=results/2026-11-25-original-full-action
python -m scripts.train_shared_full_ppo --protocol "$d/protocol.json" --manifest "$d/batch1/credits.json" --parent "$d/sft/policy.bin" --out reproduced-full-ppo1
```
