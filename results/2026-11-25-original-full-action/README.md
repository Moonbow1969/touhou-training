# Whole-credit full-action SFT and distributed PPO

All three original games use the same stochastic policy with four categorical heads: nine movement directions including neutral, focus on/off, shoot on/off and Bomb on/off. These produce 72 combinations. The games receive real keyboard input. TH13's optional title-specific manual Trance is outside the shared action space. The game still applies native mechanics, including death trance. Each worker carries the policy across life losses and Stage 2 and stops only on a verified native ending or Game Over. There are no Continues, geometric dodges, aiming corrections, or automatic Bombs.

Momentum's 5090 fitted a portable four-head SFT student using TH13/14/17 human replays and a previously trained structured human policy teacher. We used 216,350 original four-tick examples, resulting in 106,933 consecutive eight-tick action windows. The portable SFT objective mixes 85% human action targets and 15% teacher probabilities. Player groups in the four development replays are disjoint from training. The baseline uses two prior full controls and elapsed decision estimates; the historical replay shards have no corresponding original video. The weights on all 84 visual input columns start at zero. Online PPO changes the weights using current image brightness and frame differences in a 6 × 7 grid. The directly evaluated human SFT and the PPO initialization have exactly the same binary fingerprint. The first synchronous PPO update barrier received four native full credits per title (12 credits, 8,304 accepted decisions) from the frozen SFT. Training seeds are distinct from all evaluation seeds. Entropy and Steam Deck are separate TH12 deployment hosts. TH13 plays on Endeavour; TH10 plays on Momentum and Accelerator. Workers sample their own actions and journal all four action log probabilities, value estimates, visual features, input confirmation, true stage, death and resource events. The learner recomputes all recorded probabilities before updating. Each minibatch assigns each title the same loss weight. A native spare loss (including the active final life) costs 1, an earned life receives 1, stage advance receives 2, a confirmed Bomb on the same life costs 0.03, and valid play earns 0.001 per wall second. TH10 spends Power on Bombs. Its item-derived Power balance and successful activations are reported separately. The native test is whether the original game actually enters Stage 2 during a whole credit. Record original stocks at that entry, and at the final native screen. If nobody enters Stage 2, the entry balance is undefined. Controllers share random seeds in matched test credits; native game RNG is uncontrolled. Technical interruptions are recorded separately. The fixed test uses 12 seeds per title per policy. A second barrier requests eight new credits per title using PPO1 and the same training objective. [Round-two design](protocol2.json)

From the repository root a completed first-round checkpoint can be rebuilt from the released action trajectories:

```sh
d=results/2026-11-25-original-full-action
python -m scripts.train_shared_full_ppo --protocol "$d/protocol.json" --manifest "$d/batch1/credits.json" --parent "$d/sft/policy.bin" --out reproduced-full-ppo1
```


## Second update and image diagnostics

A second synchronous PPO update consumed 24 new PPO1 whole credits across TH10/12/13 (14,854 on-policy decisions). Across both updates the learner used 36 full credits and 23,158 decisions. All four optimization epochs passed the per-game KL bound for each update. [Round-two original trajectories](batch2/credits.json) · [Optimization history and action counts](ppo2/report.json) · [PPO2 weights](ppo2/policy.bin)

On 246 frames from a held TH10 credit, the same spatial probe estimated player location with median error of 149.6 original pixels from the 6 × 7 visual grid and 6.6 pixels from the original 96 × 112 observations. An inexpensive convolutional detector trained on TH10 alone achieved median errors of 8.0, 163.3 and 120.1 original pixels on separate TH10, TH12 and TH13 credits. With equal per-title training batches, the same architecture scored 34.2, 10.5 and 10.1 pixels respectively. The TH12 evaluation covers only 14 manually identified body centers. The TH13 evaluation covers 1,322 stable frames from one other credit. Frames within a credit are correlated. None of these detector tests measures the ability to clear a stage. In a separate four-seed, paired TH10 pilot that supplied estimated position and displacement to a human-trained visual SFT actor, both policies ended 0/4 at Stage 2. On held human trajectories the greedy SFT missed all 113 observed Bomb onsets. Frozen stochastic TH10 SFT and PPO1 each spent enough Power to confirm one actual Bomb activation across their respective 12 primary credits. Conditioning on sufficient Power, the policy attempted no Bomb in the half-second leading up to 11 SFT and 17 PPO1 life losses. These are counts of events, potentially several per credit. No automated Bomb or geometric avoidance was active. [Held human changes](sft/held-switches.json) · [Original TH10 sampling probabilities](../2026-11-25-full-action-th10/bomb-propensity.json)
