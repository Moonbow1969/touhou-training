# TH10 original-game camera and projectile observations

These eight NPZ files come from complete, newly sampled TH10 Normal trial credits with a frozen PPO2 policy. The game supplied the images. A separate read-only process measured player coordinates, inventory and projectiles. The policy received grayscale camera frames and its own input history during play. Each NPZ is paired with a compact behavior trace containing values, log probabilities, rewards and genuine terminal flags. The manifest records each filename, its SHA-256, the matching entry inside the behavior ZIP, its controller seed and its model hash. [Download manifest](../train-ppo2-paired-manifest.json) · [Behavior traces](../train-ppo2-native-traces.zip)

For decision index `i`, `obs[i]` is the 112-row, 96-column grayscale image and `action[i]` contains direction, focus, shoot and Bomb. Select rows with `valid[i]`, then use `k = past_native_index[i]` to join the last native sample that completed by camera time. The array `bullets[k, :min(bullet_count[k],96)]` holds projectile coordinates relative to `player_xy[k]` and native velocity in pixels per game tick. Adding the player position and then 192 to X converts each center to the 384 × 448 playfield with a top-left origin. Other fields include the original native read interval, the camera timestamp, the prior sample age, native input, Power, lives, stage and score.

The reproducible visibility experiment assigns controller seeds 710201–710205 to training, 710206 to validation, and 710207–710208 to test. All eight credits belong to the online RL training partition. They are independent of the story evaluation seeds.
