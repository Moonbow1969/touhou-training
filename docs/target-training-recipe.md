# 261123 Moonbow Toho ML | Target Training Recipe

2026 年 11 月 26 日更新。TH10、TH12、TH13、TH17 已从同一份人类 replay SFT 出发，在 Hard、Lunatic 上共同训练纯视觉全动作 PPO。第一代用了 32 局完整原作、14,578 次策略决策。分作训练、联合训练、模型权重平均已有同预算人类动作对照。原作评估按作品、难度和剩余资源独立报告。[四作 PPO 日志](../results/2026-11-26-original-camera-training/four-game-online/) · [人类动作与权重合并对照](../results/2026-11-26-original-camera-training/specialist-vs-shared/) · [论文资源](resources.md)

**项目定位。** 以东方 Project 原作为共同实验平台，建设覆盖经典控制、模仿学习、强化学习、世界模型和语言模型控制的开源基准库。工作名为 **Toho ML**，**Toho AI** 和 **Moonbow Toho ML** 可用于后续品牌讨论。长期目标是做到这个方向规模最大，用可复现的算法家族数、已验证的作品与难度覆盖、公开运行记录和实验数据规模来衡量。每次发布同时保留正结果、负结果和失败记录。

已有 TH14 Normal 灵梦 A 两次 1CC 来自 SFT、几何避弹、学习瞄准和紧急 Bomb 的组合。Hard 的固定速度控制器进入第五关。现有 PPO 训练集中在第一关的避弹头，World Model 以旁路方式预测。首轮主实验将**从已训练的 SFT 初始化完整策略**，测量在原作反馈下进行 RL 微调能带来多少进步。 [现有原作结果与日志](devlog/261123-overnight-recipes.md)

## 1. 定义避弹任务和排行榜

| 任务 | 开始条件与目标 | 主指标 |
| --- | --- | --- |
| 避弹窗口 | 从固定关卡或符卡入口开始，存活到固定帧数。主要设定关闭 Bomb，单列允许 Bomb 的版本 | 生存率、首次掉命时间，以及固定上限下的限制平均生存帧数 |
| 符卡或关卡 | 从原作 Practice Start 或同一符卡入口开始，存活并通过目标。区分击破、超时和原作判定的符卡取得 | 击破／过关率，资源消耗和用时 |
| 整局 | 原作 Story 从第一关开始，全程同一信用 | 1CC 率、最远关卡、掉命、Bomb、游戏内总用时 |
| 跨作品 | 冻结训练和选优流程后，在锁定的新作品配置上跑相同任务 | 零样本 1CC 或过关率、固定适配预算后的学习曲线 |

每项评估公布作品、原作版本、难度、机体、入口、观测权限、是否允许 Bomb、动作间隔、终止上限和推理预算。获胜、原作 Game Over、到达任务截止和环境错误各自入账。对未掉命便到达观测上限的试验标为右删失。对整局成绩同时报告有效试验分母和基础设施失败数。分数用于同一作品和配置内比较，跨作品使用通关率或明确归一化的指标。

### 观测权限

| 榜单 | 运行时可见信息 | 参赛方法 |
| --- | --- | --- |
| 像素 | 当前和历史原作画面与自己的按键历史 | 像素 SFT、像素 RL、视觉／多模态策略 |
| 结构化 | 同一观测合同下的原作当前状态与历史，例如玩家状态和附近弹幕 | 规则搜索、结构化 SFT、PPO、DQN、世界模型 |
| 可重置分支 | 有版本记录的可重置模拟环境或经过验证、支持分支的快照 | 候选动作反事实、带真动态的 MCTS、搜索 oracle |

每个结果额外记录动作由策略直接输出、由规则输出，还是经过混合控制。像素榜可以在环境侧用原作事件计算奖励和结算指标，事件通道与策略观测保持独立。原作暂停用于同步读取与动作步进。回放、Practice Start 和暂停各有不同的重置能力，只有通过同状态重放校验的入口才支持反事实分支。模拟器结果另报，原作通过率由原作执行确认。

## 2. 共同环境和数据合同

- **动作**。沿用 9 种方向含原地，外加低速、射击、Bomb 三个二值动作。分头策略用 `MultiDiscrete(9, 2, 2, 2)`，离散 Q 方法可用等价的 72 项联合动作。仅避弹窗口可以固定射击或关闭 Bomb，相关配置进结果表。整局测试由策略决定所有四个输出。
- **时间**。默认一决策四个原作帧。单独消融两帧、八帧动作间隔，按实际原作帧对齐训练预算、观察历史跨度和折扣。记录重复帧、漏帧、实际步长和推理 p50／p95／p99。高延迟策略同时报告暂停步进成绩和实时成绩，分别标注。
- **记录**。每条轨迹可追溯到游戏版本、入口、策略哈希和数据快照。状态、实际送达的动作、原作事件和终止原因可对齐。按键窗口、对齐的状态—动作对、带回报的在线轨迹、世界模型转移、偏好对分别计数，发布来源、角色、难度和玩家覆盖。
- **隔离**。训练、验证、测试以玩家和完整 replay 分组。常规 TH17 留出玩家用于历史对照，独立的 TH13／TH14 → TH17 用于整作品迁移。TH15／18／19 保留为整作品测试，正式评估前冻结权重和配置。TH08／10 先验证原作接入、动作语义和回放对齐，在见到正式成绩前登记各自用途。现有结构化 SFT 有 168,136 条候选语料，已实跑的版本使用 147,560 条。历史 4,516 万独立按键窗口来自另一条行动先验数据线。 [数据与采集协议](experiments.md)

作品适配器提供 Gymnasium 风格的 `reset`／`step`、原作任务事件与能力声明，包括观测类型、Practice 入口和是否支持可验证分支。采集器与 trainer 共用版本化的轨迹格式，评估器在同一任务配置下加载规则、训练权重或远程模型。算法可以接成熟实现，随结果记录库版本与改动。一次低成本的运行检查用于验证接线，正式结果另用原作运行记录和回放复核。

## 3. 规则与搜索

| 方法 | 复现设定与要测的差异 |
| --- | --- |
| 站桩、均匀随机、保持上一方向 | 所有榜单的最小基线。整局加一个固定射击版本 |
| 反应式净空、势场、速度障碍 | 比较即时移动、匀速外推和不同安全边距。测死角、轨迹抖动、计算量和 Bomb 消耗 |
| BFS、DFS、迭代加深、Dijkstra | 用同一时间展开的运动图与碰撞检测器。BFS 测最早可行步数，Dijkstra 测带净空和资源代价的路径，DFS 测固定节点预算下的可行性 |
| A*、Weighted A*、Beam Search | 状态至少包含位置、时间与动作状态，障碍跟随原作帧变化。比较不同搜索宽度、节点上限和每步重规划。对 A* 的最优性声明以有效的图、代价和启发式下界为条件 |
| MPC、CEM、随机射击、MCTS | MPC 每次执行计划的第一步。CEM 或随机射击在固定预算内搜索动作序列。MCTS 在可复现的分支环境或已校验的模型内展开，机器性能按节点数与时间同时报告 |
| 脚本规则与历史混合控制器 | 保留现有几何、瞄准、紧急 Bomb 和速度估计作为可单独开关的对照，做去除组件的实验 |

首轮规划器共用同一弹幕外推器与玩家运动模型。先比较 12、24、48 帧视野，记录命中前误判净空、无解率和每步扩展数。移动速度误差、直线激光、弹幕转向和新生成物单独分层。完成规则组后，同一张评估表接入学习算法，固定各自观测合同。 [A* 原论文](https://ieeexplore.ieee.org/document/4082128)

## 4. 经典学习算法到全策略 RL

| 算法家族 | 最低覆盖 | 重点问题 |
| --- | --- | --- |
| 表格 RL | Q-learning、SARSA、Expected SARSA、Dyna-Q | 小型避弹校验环境或明确的离散状态抽象，以小状态空间验证更新语义 |
| 价值学习 | DQN、Double DQN、Dueling、C51／QR-DQN、Rainbow | 联合离散动作，记录相同原作帧预算下的样本效率。拆出多步回报和优先经验回放 |
| 策略梯度和 Actor–Critic | REINFORCE、A2C、PPO、TRPO、离散 SAC | 从同一 SFT 进行完整策略微调时，在线学习分别在哪类关卡带来收益 |
| 部分可观测与分布式 | Recurrent PPO、DRQN／R2D2、IMPALA／V-trace | RNN 或 Transformer 历史的收益，增加并行原作实例后的吞吐与策略滞后 |
| Imitation 和离线 RL | BC／SFT、DAgger、DQfD、IQL、CQL、AWAC、Decision Transformer | 纯专家回放与混入失败／探索轨迹时，离线排序表现能否转成原作进度。DAgger 的教师查询、DQfD 的演示预训练分别登记 |
| 课程与层级 | Practice → Story、稀有符卡重采样、Options／层级策略、技能蒸馏 | 短窗口避弹是否能迁移到资源规划和整局。单独消融训练入口与课程顺序 |

离线 RL 需要可对齐的转移和奖励。已有按键先验语料可用于序列预训练。原作事件对齐后，才把这些数据用于价值学习。滚动采样必须保留版本身份和策略来源，以便检查 offline 到 online 的收益。 [PPO](https://arxiv.org/abs/1707.06347) · [Rainbow](https://arxiv.org/abs/1710.02298) · [DAgger](https://proceedings.mlr.press/v15/ross11a.html) · [CQL](https://arxiv.org/abs/2006.04779) · [IQL](https://arxiv.org/abs/2110.06169) · [Decision Transformer](https://arxiv.org/abs/2106.01345)

### 第一条可执行的主配方

1. 冻结 TH14 已实跑的 **147,560 条 SFT checkpoint** 和原输入格式。三臂共用同一原作版本与位置起点。先跑冻结 SFT 直出、同权重初始化的全策略 PPO、现有混合控制器。全策略 PPO 初始化时核对所有动作头的 logits 与冻结 SFT 一致，价值头单独初始化。冻结 SFT 和 PPO 两臂全程直出动作，规则避弹、自动瞄准和紧急 Bomb 只存在于混合基线。
2. 使用 **TH14 1.00b、Normal、灵梦 A、四帧一决策**。第一关做环境和动作链路 smoke。第四、第五关 Practice 报掉命、Bomb、击破方式、过关率。独立整局从第一关重新跑到原作结算，报 1CC。Practice 的初始资源按原作分别记录。按版本固定入口，在不同方法间轮换评估次序。只有验证过相同初始状态的场景才用配对估计。
3. 用原作任务事件定义回报。避弹窗口的事件是到达时限或第一次掉命。符卡和关卡任务以击破／过关事件得分。整局以 1CC 为终点目标。额外死亡惩罚、关卡进度奖励和 score shaping 作为单独消融。内在奖励仅用于训练，最终成绩仍按原作事件统计。
4. 起始 PPO 设置为 `clip=0.15`、`γ=0.997` 每四帧、`GAE λ=0.95`、`lr=8e-5`，并与历史避弹头配置区分。先跑 **32k → 128k → 1M** 原作决策三个档，同档固定帧数与调参预算，随档报告学习曲线和实际算力。按 60 fps，单实例 1M 个四帧决策约 **18.5 小时**纯游戏时间，还需计入菜单、复位与暂停开销。H100 用于 learner、批量推理及离线实验，并行效率按实际 rollout 吞吐确认。
5. 初筛用三个训练种子和每种子 20 次短任务评估。报告长期 1CC 时扩大到至少五个训练种子，每种子十局完整游戏，公布逐局数据及按种子聚类的区间。资源有限时照实标记 pilot。确认 TH14 Normal 后加 Hard、Lunatic 及多机体，并在锁定的留出作品复测。 [小样本深度 RL 评估](https://arxiv.org/abs/2108.13264)

## 5. Exploration 和轨迹偏好

- **探索奖励**。先记录 PPO 的熵与实际动作分布，再比较熵／温度调节、计数或哈希探索、ICM、RND、episodic novelty／NGU，条件允许再做 Go-Explore。Go-Explore 需要验证可恢复的状态或可重放的轨迹前缀。按进度和风险分桶看是否访问了新的有效状态。将内在回报和外在回报分开记，检查原地刷分、反复掉命、背景动画新奇和拖延击破等行为。探索模块保持相同的外在评估。 [ICM](https://arxiv.org/abs/1705.05363) · [RND](https://arxiv.org/abs/1810.12894) · [NGU](https://arxiv.org/abs/2002.06038)
- **DPO**。做离线的**轨迹偏好**实验。以同一个观测或已校验的短前缀为条件，对固定预算的两段实际动作序列排序。优先比较达成任务、避开掉命、节省 Bomb 和用时，规则阈值与并列处理预先登记。冻结同一 SFT reference，用动作序列似然做偏好优化。用等长片段或明确结束语义控制长度偏差。和同样数据上的 BC、成功轨迹重采样、显式偏好奖励模型＋PPO 对照。DPO 主结果用原作闭环成绩，同时报告偏好准确率和偏好标签来源。 [DPO](https://arxiv.org/abs/2305.18290)

## 6. World Model 与高级控制

1. 先跑匀速外推和已有占据栅格做基线。比较实体位置与速度预测、时空占据、像素 RSSM 或 action-conditioned Transformer。评估 4／12／24／48 帧，分开统计整体 AP、近身 AP、低概率碰撞漏检、位置误差和多步漂移。
2. 保留三个对照臂。用相同计划器分别接物理外推和学习模型，另外把学习模型开成 shadow。同一候选集合和推理预算下比较动作排序与原作结果。反事实排序标签来自已校验的可分支场景，录制轨迹用于观测动作上的预测评估。
3. 逐个实现 MBPO、DreamerV3、TD-MPC2、MuZero／EfficientZero。Dreamer 系列测潜空间训练，TD-MPC 系列测学习价值引导的实时规划，MuZero 系列测学习动态中的树搜索。统一核算真实原作帧、虚拟模型步、训练算力、单步推理用时和模型失配。阶段成果以原作清关和样本效率为主。 [DreamerV3](https://www.nature.com/articles/s41586-025-08744-2) · [TD-MPC2](https://arxiv.org/abs/2310.16828) · [MuZero](https://arxiv.org/abs/1911.08265)

## 7. LLM／VLM 和 GRPO

让大模型先做**短程计划或资源决策**，例如在固定节奏输出未来 8／16 步动作块，或在阶段／符卡切换时输出策略条件。执行期间由专门训练的小策略处理每四帧的动作。另做直接输出离散按键的实验，测暂停步进与实时两种预算。语言解释独立记录，比较它是否实际改变闭环决策。用同等观测、动作时限和预算的小型 Transformer 作对照，再增加文本计划、视觉输入、上下文或工具接口。公开训练数据可见范围，预训练模型的已知游戏知识按单独来源记。

**GRPO 有实验价值，尤其是宏动作和可批量重置的短任务。** 对同一开局条件按当前策略采样一组候选动作块或短轨迹，用原作事件给分，在组内计算相对优势，更新计划策略。先做 4／8 个候选，单列全平分比例和有效组数。按总原作帧与实际耗时和 PPO、DPO、best-of-N 比较，固定每种方法能看到的反馈。长整局要保留相同开局条件、足够多的组内非平分回报及可重置吞吐，才能评价这种方法的性价比。GRPO 的使用条件来自任务的采样结构，模型尺寸单独报告。 [DeepSeekMath 原论文](https://arxiv.org/abs/2402.03300)

## 8. 实现顺序与发布标准

| 阶段 | 交付 | 实验完成的判据 |
| --- | --- | --- |
| 第一版避弹基准 | TH14 原作环境、固定场景、站桩／随机、几何、BFS／Dijkstra、A*／Beam、冻结 SFT | 每一类走完整评估脚本，带随机种子、原作结算和可复现配置 |
| 第一版全策略学习 | SFT 初始权重、全策略 PPO、DQN 系列、一个离线 RL 基线 | 发布纯策略与混合策略的等预算结果，包含第一关、后段和整局 |
| 多作品与探索 | 观测合同一致的多作品适配、Hard／Lunatic、多机体、探索和 DPO | 发布跨玩家和跨作品独立结果、失败日志和每个采集分片的覆盖统计 |
| 高级控制 | World Model 规划、Dreamer／MuZero 系列、LLM／VLM／GRPO | 原作测得闭环效果，公开真实环境帧、模型计算和延迟成本，给出有益或无益的判定 |

一个方法从「候选」升级为「已复现」，需要对应原作×任务×观测矩阵里的实跑结果、固定预算、完整配置、输入／checkpoint 哈希、逐局记录、训练日志、实现偏差与可运行命令。发布版本同时计数覆盖的算法家族、累计有效原作帧、对齐专家决策、成功复现的运行数和待验证单元。设备配置、训练/验证/测试清单、超参数试验总预算、脚本版本和检查点选择理由随结果存档。游戏本体及许可受限的资产由本地用户提供，公开复现用合规清单与校验哈希。
