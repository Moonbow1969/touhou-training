# Research references

For the current work, read PIFE for the observation interface, Sutton and Barto Chapters 3 and 13 for the objective, GAE and PPO for the update, Sample Factory and IMPALA for the rollout system, DreamerV3 for imagined training, and WARP and Model Soups for checkpoint merging. See the [system design](design.md), [experiment protocols](experiments.md) and [distributed rollout report](distributed-rollouts.md) for how these ideas are tested on Touhou.

## Reinforcement learning foundations

| Reference | Application to Touhou |
| --- | --- |
| Sutton and Barto, *Reinforcement Learning: An Introduction*, 2nd ed. (2018). | Read Chapters 3, 6–7 and 13 for MDPs, bootstrapping, multi-step targets and policy gradients. Define a decision, its four native ticks, episode boundaries and survival rewards before choosing an algorithm. [Book](https://mitpress.mit.edu/9780262039246/reinforcement-learning/) |
| Sutton et al., *Policy Gradient Methods for Reinforcement Learning with Function Approximation* (NeurIPS 1999). | Derives the policy gradient with function approximation. The score-function identity applies to the joint log probability of the movement, focus, shoot and bomb heads. [Paper](https://proceedings.neurips.cc/paper/1999/hash/464d828b85b0bed98e80ade0a5c43b0f-Abstract.html) |
| Schulman et al., *High-Dimensional Continuous Control Using Generalized Advantage Estimation* (ICLR 2016). | Use the bias–variance trade-off in `lambda` when credit for a miss spans several dodge decisions. Calculate advantages per uninterrupted trajectory and bootstrap from the last observation at a time limit. [Paper](https://arxiv.org/abs/1506.02438) |
| Schulman et al., *Trust Region Policy Optimization* (ICML 2015) and *Proximal Policy Optimization Algorithms* (2017). | TRPO motivates limiting policy change. PPO’s clipped ratio uses the acting policy’s log probabilities and permits several update epochs on a fresh batch. Track KL, clip fraction and entropy by action head when a warm-started policy collapses to idle. [TRPO](https://proceedings.mlr.press/v37/schulman15.html) · [PPO](https://arxiv.org/abs/1707.06347) |
| Engstrom et al., *Implementation Matters in Deep Policy Gradients* (ICLR 2020). | Record observation scaling, initialization, optimizer, advantage normalization and clipping alongside algorithm names. Fix those details for matched PPO comparisons. [Paper](https://arxiv.org/abs/2005.12729) |
| Mnih et al., *Human-level Control through Deep Reinforcement Learning* (Nature 2015), and Hessel et al., *Rainbow* (AAAI 2018). | Read for pixel-based Q-learning, replay and distributional value learning. A compact dodge action space makes a tractable first Q-learning baseline alongside the four-head actor. [DQN](https://doi.org/10.1038/nature14236) · [Rainbow](https://arxiv.org/abs/1710.02298) |
| Burda et al., *Exploration by Random Network Distillation* (ICLR 2019). | A concrete intrinsic-reward ablation. Separate actual stage progress from novelty due to cosmetic changes or unfamiliar visual effects. [Paper](https://arxiv.org/abs/1810.12894) |
| Agarwal et al., *Deep Reinforcement Learning at the Edge of the Statistical Precipice* (NeurIPS 2021). | Preserve per-seed returns and uncertainty before promoting a recipe. Group replay splits by player and stage and show paired differences on matched native trials. [Paper](https://arxiv.org/abs/2108.13264) |

## Imitation, offline learning and preferences

| Reference | Application to Touhou |
| --- | --- |
| Ross et al., *A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning* (AISTATS 2011). | DAgger explains why small imitation errors compound on learner-visited states. Replay behavior cloning can initialize the policy. A DAgger variant additionally needs expert labels for the states reached during learner rollouts. [Paper](https://proceedings.mlr.press/v15/ross11a.html) |
| Zhao et al., *Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware* (RSS 2023). | ACT predicts a sequence of robot actions from an observation. The Touhou experiment tests a smaller question with discrete controls. Can one game image support two successive commands inside four native ticks, at the same camera and model budget as a single held command? [Paper](https://www.roboticsproceedings.org/rss19/p016.html) · [Four-title study](../results/2026-11-26-original-camera-training/four-title-subwindow-sft/protocol.json) |
| Kumar et al., *Conservative Q-Learning for Offline Reinforcement Learning* (NeurIPS 2020), and Kostrikov et al., *Offline Reinforcement Learning with Implicit Q-Learning* (ICLR 2022). | Offline RL baselines for aligned replays with rewards and episode boundaries. Compare action coverage by shot type, difficulty and stage, then evaluate both offline checkpoints and their online descendants. [CQL](https://arxiv.org/abs/2006.04779) · [IQL](https://arxiv.org/abs/2110.06169) |
| Chen et al., *Decision Transformer: Reinforcement Learning via Sequence Modeling* (NeurIPS 2021). | A sequence baseline for combining recent actions, states and return targets. Test whether the same context improves first-miss survival and clear rate under autoregressive control. [Paper](https://arxiv.org/abs/2106.01345) |
| Christiano et al., *Deep Reinforcement Learning from Human Preferences* (NeurIPS 2017), and Rafailov et al., *Direct Preference Optimization* (NeurIPS 2023). | Read if adding human comparisons of replay segments. Preferences such as conservative routing or bomb timing form a distinct training signal from survival rewards. [Preference-based RL](https://arxiv.org/abs/1706.03741) · [DPO](https://arxiv.org/abs/2305.18290) |
| Shao et al., *DeepSeekMath* (2024). | Original GRPO reference for experiments that sample several candidate outputs under a common prompt and compare their rewards. A possible fit for a language model choosing high-level plans, with separate experiments for per-tick game control. [Paper](https://arxiv.org/abs/2402.03300) |

## World models, imagination and planning

| Reference | Application to Touhou |
| --- | --- |
| Sutton, *Integrated Architectures for Learning, Planning, and Reacting Based on Approximating Dynamic Programming* (ICML 1990). | The Dyna architecture connects data from acting, a learned model and planning updates. Keep real and model-generated samples identifiable when combining them. [Paper](https://www.sciencedirect.com/science/article/abs/pii/B9781558601413500304) |
| Ha and Schmidhuber, *World Models* (2018). | Historical starting point for encoding observations, learning temporal dynamics and training a controller in an imagined environment. Keep separate counters for native interactions and imagined transitions. [Paper](https://arxiv.org/abs/1803.10122) |
| Hafner et al., *Learning Latent Dynamics for Planning from Pixels* (ICML 2019). | PlaNet introduces recurrent latent dynamics and online planning. Compare short-horizon learned action ranking with geometric clearance and constant-velocity forecasting on matched native states. [Paper](https://proceedings.mlr.press/v97/hafner19a.html) |
| Janner et al., *When to Trust Your Model: Model-Based Policy Optimization* (NeurIPS 2019). | Start short imagined rollouts from states visited in the original game. Sweep horizon against native first-miss and clear rates to measure the effect of compounding model error. [Paper](https://arxiv.org/abs/1906.08253) |
| Hafner et al., *Dream to Control: Learning Behaviors by Latent Imagination* (ICLR 2020). | DreamerV1 trains actor and critic on latent imagined trajectories. A first implementation can use structured projectile states and validate multi-step model error before relying on imagined returns. [Paper](https://arxiv.org/abs/1912.01603) |
| Hafner et al., *Mastering Atari with Discrete World Models* (ICLR 2021). | DreamerV2 is a closer starting point for games with discrete actions. Study categorical latents, continuation prediction and credit assignment through imagined actions. [Paper](https://arxiv.org/abs/2010.02193) |
| Hafner et al., *Mastering Diverse Control Tasks through World Models* (Nature 2025). | DreamerV3 is the main world-model implementation reference. Read the paper and appendix for scale transformations, distributional returns, model losses and cross-task evaluation. Measure transfer across title, shot and difficulty with fixed native budgets. [Paper](https://doi.org/10.1038/s41586-025-08744-2) · [Author code](https://github.com/danijar/dreamerv3) |
| Schrittwieser et al., *Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model* (Nature 2020). | MuZero learns dynamics useful for planning by predicting reward, value and policy. It motivates testing whether an accurate dodge ranking can come from a compact model without decoding every projectile. [Paper](https://doi.org/10.1038/s41586-020-03051-4) |
| Hansen et al., *TD-MPC2: Scalable, Robust World Models for Continuous Control* (ICLR 2024). | Reference for combining short latent planning with a terminal value and for conditioning dynamics across tasks. A Touhou implementation needs to adapt its planner to the factored discrete action space. [Paper](https://arxiv.org/abs/2310.16828) |

## Parallel collection and distributed RL

| Reference | Engineering application |
| --- | --- |
| Mnih et al., *Asynchronous Methods for Deep Reinforcement Learning* (ICML 2016). | Historical reference for parallel environment instances. Compare isolated processes with sequential collection under an equal interaction budget. [Paper](https://proceedings.mlr.press/v48/mniha16.html) |
| Liang et al., *RLlib: Abstractions for Distributed Reinforcement Learning* (ICML 2018). | Separates sampling, execution and learning primitives. Use the actor/learner boundary as a reference for host placement, worker failures and reproducible ownership of experiment state. [Paper](https://proceedings.mlr.press/v80/liang18b.html) |
| Espeholt et al., *IMPALA: Scalable Distributed Deep-RL with Importance Weighted Actor-Learner Architectures* (ICML 2018). | The reference for decoupled actors and learner with policy lag. Start with one frozen policy version per PPO batch. If later allowing asynchronous actors, measure sample age and evaluate a correction such as V-trace with its own baseline. [Paper](https://proceedings.mlr.press/v80/espeholt18a.html) |
| Espeholt et al., *SEED RL: Scalable and Efficient Deep-RL with Accelerated Central Inference* (ICLR 2020). | Compare local CPU inference with batched central accelerator inference when model size or actor count justifies RPC. Measure serialization, network delay and accelerator occupancy separately. [Paper](https://arxiv.org/abs/1910.06591) |
| Petrenko et al., *Sample Factory* (ICML 2020). | Design reference for multiple environments per worker, batched inference and overlapping data collection. Profile decision timing, reset, observation decoding and learner updates before copying throughput optimizations. [Paper](https://proceedings.mlr.press/v119/petrenko20a.html) |
| Weng et al., *EnvPool: A Highly Parallel Reinforcement Learning Environment Execution Engine* (NeurIPS 2022). | Reference for a fast compiled environment boundary and asynchronous vectorized stepping. Original Touhou still needs one independently controlled game per active instance. A compatible API does not give the original a batched simulation backend. [Paper](https://arxiv.org/abs/2206.10558) · [Code](https://github.com/sail-sg/envpool) |
| Farama Foundation, *Gymnasium Terminated/Truncated Step API*, and Stable Baselines3 PPO documentation. | Check terminal masks, final observations and `n_steps × n_envs` before substituting a remote vector environment. Compare buffer contents and resulting returns against the local implementation. [Gymnasium](https://farama.org/Gymnasium-Terminated-Truncated-Step-API) · [SB3](https://stable-baselines3.readthedocs.io/en/v2.5.0/modules/ppo.html) |

## Weight averaging and independent agents

| Reference | Application to a merging experiment |
| --- | --- |
| Wortsman et al., *Model Soups* (ICML 2022). | Test a uniform average of branches sharing exactly one parent, then compare it with every individual branch and a validation-selected branch. The reported experiments are supervised, so run game trials on the merged policy. [Paper](https://proceedings.mlr.press/v162/wortsman22a.html) |
| McMahan et al., *Communication-Efficient Learning of Deep Networks from Decentralized Data* (AISTATS 2017). | FedAvg is the reference for repeated local-update/aggregate rounds. A one-shot merge of three PPO descendants measures a different intervention. Keep equal local budgets before testing weighted or repeated averaging. [Paper](https://proceedings.mlr.press/v54/mcmahan17a.html) |
| Ramé et al., *WARP: On the Benefits of Weight Averaged Rewarded Policies* (2024). | Direct reference for merging independently fine-tuned RL policies and interpolating toward their common initialization. Treat one-shot averaging, interpolation and the full iterative procedure as separate experiments. [Paper](https://arxiv.org/abs/2406.16768) |
| Jin et al., *Federated Reinforcement Learning with Environment Heterogeneity* (2022). | Useful when workers specialize in distinct environments. Treat differences in difficulty, shot and title as a testable source of parameter drift. Keep a homogeneous three-worker run as a control. [Paper](https://arxiv.org/abs/2204.02634) |

## Touhou and bullet-hell research

| Reference | System and use |
| --- | --- |
| Itoi and Simo-Serra, *PIFE: Permutation Invariant Feature Extractor for Danmaku Games* (IEEE CoG 2022). | Direct Touhou precedent using live memory and an order-invariant object encoder on TH09, *Phantasmagoria of Flower View*. For TH14, compare unordered aggregation and attention with identical projectile caps, features and compute. TH09 versus-mode results are a separate benchmark. [Paper](https://ieee-cog.org/2022/assets/papers/paper_221.pdf) · [Publication record](https://waseda.elsevierpure.com/en/publications/pife-permutation-invariant-feature-extractor-for-danmaku-games/) |
| Zaheer et al., *Deep Sets* (NeurIPS 2017), and Lee et al., *Set Transformer* (ICML 2019). | General arguments for permutation-invariant inputs. Test shared per-bullet features plus a pooled summary before paying for pairwise attention. Shuffle entity order at validation time and measure CPU inference cost. [Deep Sets](https://arxiv.org/abs/1703.06114) · [Set Transformer](https://proceedings.mlr.press/v97/lee19d.html) |
| Fujimoto, *An Agent Playing a Bullet Hell Game Using Reinforcement Learning* (IPSJ Game Programming Workshop 2024). | Pixel-only bullet-hell study comparing input representations and components of Rainbow. Its categorical DQN result motivates a distributional-value baseline on a compact dodge action set. [Paper](https://ipsj.ixsq.nii.ac.jp/record/240726/files/IPSJ-GPWS2024008.pdf) · [Bibliographic record](https://cir.nii.ac.jp/crid/1050865187563177728) |
| Hart, Nilsson and Raphael, *A Formal Basis for the Heuristic Determination of Minimum Cost Paths* (1968). | The A* baseline can search space–time cells over a short horizon, with hazards evaluated at their predicted arrival time. Report the planner’s observation access, horizon, compute budget and failure rate on the same native trials used for learned controllers. [Paper](https://doi.org/10.1109/TSSC.1968.300136) |
| Khalifa et al., *Talakat: Bullet Hell Generation through Constrained Map-Elites* (GECCO 2018). | Procedural testbed with best-first playtesting and separate strategy and dexterity parameters. Read for planning baselines and controlled pattern difficulty. [Paper](https://arxiv.org/abs/1806.04718) |
| Wang, Liu and Yannakakis, *Keiki: Towards Realistic Danmaku Generation via Sequential GANs* (2021). | Pattern generation and representation reference. Generated patterns are useful controlled stress tests for near miss timing, extrapolation and generalization. [Paper](https://arxiv.org/abs/2107.02991) |

### Implementations and data sources

- **ParaKit** supplies reference offsets and structured memory extraction. Pin the revision and verify the executable before reusing field layouts or timers. [Repository](https://github.com/Guy-L/parakit)
- **thprac** helps set up repeatable native practice trials by stage or spell. Record the practice setup in each run and report story-mode outcomes separately. [Repository](https://github.com/touhouworldcup/thprac)
- **threp** documents replay decoding. Use it to cross-check input words, then verify their alignment to native state separately. [Repository](https://github.com/Fluorohydride/threp)
- **LunAI** has a Touhou-style pygame environment, PPO ablations and CPU profiling of projectile observation construction. Reuse the profiling method and distinguish its simulation results from the original game's native timings. [Experiment code](https://github.com/Tweet-META/LunAI/tree/experiments)
- **CleanRL** is useful for auditing the PPO objective, rollout buffer and timeout semantics in a single-file implementation before optimizing transport. [Paper](https://www.jmlr.org/papers/v23/21-1342.html) · [Code](https://github.com/vwxyzjn/cleanrl)
